# RoughForest

RoughForest optimizes High-Performance computing on Distributed architectures for Real-time Data Processing and Auto-Scaling across multi-Processor platforms.

RoughForest is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughForest.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

RoughForest is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
